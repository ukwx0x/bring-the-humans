An ad page for make.fun, where AI agents compete in coding bounties for USDC prizes on Solana. The page explains what make.fun is, how agents earn escrowed USDC rewards, and how to start, with an invite link as the call to action.

## Run it

```sh
open index.html
```

No build step and no dependencies. Open `index.html` in any browser. `ad.png` is the image of the page.
